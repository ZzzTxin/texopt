## 2 三点根因（都可从数据直接读出）

### 2.1 band 太宽 → 8/20 页模型分为 0，排序靠并列噪声

`score == 0` 的页：#1–#8。逐维“损失恒为 0”的页数：

| 指标 | loss==0 | band |
|---|---|---|
| bottom_blank | 20/20 | [0, 0.22] |
| top_blank | 20/20 | [0, 0.12] |
| left_blank / right_blank | 18/20 | [0, 0.18] |
| max_gap | 16/20 | [0, 0.15] |
| ink_ratio | 15/20 | [0.02, 0.15] |
| top_bottom_ratio | 14/20 | [0.7, 1.4] |

band 内不罚分的设计，在真实已录用论文上等于“几乎不罚”→ 模型区分度被抹平。
人的前 5 名里有 4 页模型分为 0.0000，只能靠并列顺序凑名次。

### 2.2 ink_ratio 的 band 方向与人的偏好相反

- 原始值 vs 人的好坏：ρ = **+0.4977**（越“满”人越喜欢）
- band 损失 vs 人的好坏：ρ = **−0.1482**（越满模型越罚，因为上界 0.15）
- 人的最优 #5 ink=0.149（正好贴在上界），最差 #20 ink=0.058（稀疏+上下失衡）

即：`ink_ratio` 上界罚“过满”这一支，与这批样本的人眼偏好冲突。

### 2.3 人并不惩罚页底留白，模型只把它当违规

- bottom_blank 原始值 vs 人的好坏：ρ = **+0.4195**（留白多的页反而排得更好）
- 模型：band [0, 0.22]，超出才罚 → 全样本无响应

人的“最差”是**内容稀疏但上下失衡**（#20: ink 0.058 / max_gap 0.284 / tbr 2.296），
而不是留白多。当前模型把“留白多”和“留白失衡”混在一个减分项里了。

### 2.4 唯一真正有信号的是 max_gap 的 band 损失（0.5421）

说明“大片空洞”这个量纲是人对的，问题在其余维的**截断形式**。

## 3 建议（按性价比排序，动手前不建议碰权重）

1. **先改形式，不改权重**：把 A_soft 从“band 内=0、band 外线性罚”改成
   **软目标 + 两侧平滑**（如高斯/双曲距离，无平台区），否则 8/20 并列永远存在。
2. **ink_ratio 改单向**：只罚“过空”，不罚“过满”；上界单独设一个高得多的满版阈值。
3. **把“留白量”和“留白均衡”拆开**：bottom_blank 单独不该罚，应由
   `top_bottom_ratio` + `max_gap` 承担“失衡/空洞”。
4. **样本扩容**：20 页 → 30–40 页，并且**禁止并列**（强制 1..N 全序），
   或者改用成对比较（8 对才有结论、30 对稳），排序的绝对名次噪声太大。
5. 权重标定（λ、w）放到 1–4 之后再谈；现在分母都没定型。
