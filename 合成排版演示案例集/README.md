每例的“页面对比/全部页面前后对照.pdf”可快速浏览，但不代替两个独立完整PDF。

优化前后正文、数据、公式、图文件不改。末页正常留白保留；程序的NEEDS_REVIEW状态和软视觉评分上升也如实记录，不为凑成功结论改权重。

复现：在“原始源码”或“模型处理后源码”目录用XeLaTeX编译main.tex两遍。需TeX Live及Windows中文字体。原稿工程与图表自包含；优化器脚本需要从texopt仓库环境运行。

附录片段需要中文支持及graphicx、booktabs、hyperref宏包。复制到文章时，可在主稿中定义`\syntheticAssetRoot`为本目录相对路径，并在`\appendix`之后`\input`该片段；独立预览入口为`appendix_preview.tex`。
