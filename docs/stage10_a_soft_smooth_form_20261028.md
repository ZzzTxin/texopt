# Step 2-b：A_soft 软指标改成「平滑目标」形式（2026-10-28）

> 起因：20 页人工排序验收 Spearman **0.3146**（门槛 0.6），且 20 页里 **8 页总分恰为 0**。
> 结论：问题不在权重，在**形式**——「带内一律 0」把排序信号抹平了。

---

## 1　改了什么

### 1.1 旧形式（2026-09 ~ 10-27）

```python
loss = W_low·max(0, lo-x)/N + W_high·max(0, x-hi)/N      # N = hi - lo
```

带内损失恒为 0 → 大多数已录用论文的页都落在带内 → 大量并列。
实测：bottom_blank / top_blank 损失 **20/20 页为 0**，ink 15/20，max_gap 16/20。

### 1.2 新形式（`texopt/score.py` `SOFT_SPEC` + `soft_metric_loss()`）

```python
d    = |x - t| / s_side            # 对数指标先取对数
loss = w · (1 - exp(-d²/2))        # ≤ w，目标处 0，两侧严格单调，无平台区
```

- **目标 t**：该指标在 3898 页已录用语料里的**中位数**；
- **尺度 s**：t 到 p5（下侧）/ p95（上侧）的距离（下限 0.02，避免退化）；
- **单侧**：某一侧 `s=None` → 该侧不罚；
- **有界**：单指标损失 ≤ w ≤ SOFT_LOSS_CAP，极端页不吃掉全部权重。

单侧设定依据人工排序数据（`workbench-detector/rank_analysis_20261028.md`）：

| 指标 | t | s_low | s_high | w | 依据 |
|---|---|---|---|---|---|
| ink_ratio | 0.120 | 0.076 | — | 1.0 | 原始值 ρ=+0.50：人偏好“更满”，只罚过空 |
| bottom_blank | 0.066 | 0.025 | — | 0.8 | ρ=+0.42：多留白不罚，只罚贴边 |
| top_blank | 0.079 | 0.047 | 0.039 | 0.5 | 两侧都罚 |
| max_gap | 0.100 | — | 0.244 | 1.4 | 只罚大片空洞 |
| band | 0.004 | 0.030 | 0.051 | **0.0** | Step 2 判暂缓（语料仅 5% 在带内，量本身不可用） |
| left_blank | 0.091 | 0.022 | 0.130 | 0.4 | 两侧都罚 |
| right_blank | 0.115 | 0.036 | 0.100 | 0.4 | 两侧都罚 |
| top_bottom_ratio | 1.031 | 0.515 | 1.292 | 1.0 | 对数空间，尺度来自 log(p5/p50)、log(p95/p50) |

`SOFT_BANDS` 保留但**只用于报告口径**（`detector_check.py` / `corpus_analyze.py` 的带命中率），不参与打分。

## 3　诚实的边界

1. 参数 t/s 来自**语料**（独立数据），但“单侧化”的方向判断来自这 20 页，
   所以 0.4586 不是完全盲测；真正的验证要**新样本**。
2. 20 页的 Spearman 标准误很大（n=20 时约 ±0.2），0.46 与 0.6 的差距不足以断言“模型不行”，
   但足以断言“旧形式的 0 平台必须去掉”——因为那是结构性缺陷，不依赖样本量。
3. 权重（w）没有动，也**不应该**在这 20 页上动（会过拟合）。权重标定放到样本 ≥30 之后。

---

## 4　下一步

1. **扩样本**：30–40 页，**强制 1..N 无并列全序**（现在的表已经不允许并列，但页数太少）；
   或改成成对比较（可分性配对，30 对起）。
2. 新样本只用于**验收**，不回头调参；若不达标，再按逐维 rho 决定「剔除 / 改形式 / 改 t·s」。
3. 权重标定（w、λ）放在验收通过之后。
