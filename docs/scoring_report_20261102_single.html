2.1 门内定向修复：连档压页的「暂存链」

TeX 断页是台阶式的：收一档边距常常一页不减，要连收两三档才兑现。旧逻辑要求 每个单步都严格减页，于是第一档就被回滚并永久拉黑——「多档才减页」的修复永远不可能发生。 阶段 15 改为暂存链：

单步结果处理目的
兑现（违规减少 / 页数减少）本步 + 此前所有暂存档一并提交不丢组合收益
不增违规、不增页暂存，保留状态继续往下压允许台阶式推进
变差（违规变多 / 页数变多）回滚不倒退
暂存达 3 档仍未兑现整链回滚到链首不把累计破坏留在稿子里

实测靶稿（8 段 × 6 句，A4/10pt）：25mm→2 页、23mm→2 页、21mm→1 页。 把上限设为 1（= 旧行为）仍然 BLOCKED_GATE；默认 3 则压进 1 页且边距 ≤21mm； 「怎么收都不减页」的稿子会整链回滚、边距回到 25mm。

3.2 ρ：缺陷 ↔ 代价的汇率

口径是等边际收益：修 1 单位缺陷的质量收益，恰好抵消 1 单位干预代价。 测量方式不是从闭环里统计「已经发生的修复」（那会偏向"修得值"的一侧， 旧值 0.341 就是这么来的），而是直接问人：

轮次设计结果
第一轮5 类缺陷 × 3 档边距（+12/20/30mm）+ 空题中位 ρ = 16.7
第二轮边界加密 + 字号货币 + 空题中位 ρ = 13.3
一致性复核3 道空题 + 3 道明显差异题6/6 通过
取值两轮中位ρ = 15，区间约 [5, 32]（单人评分、5 类缺陷）

含义：修 1 个加权缺陷，在人眼里约值 15 个代价单位——即愿意用 30mm 级别的 边距改动去换。这也是「模型过去过于死守原版心」的量化解释。

3.3 口径统一：从 c* 到落地权重

7 项从两套不可比的口径（人判严重度 ÷ 语料频率；9 月手拍先验）统一到 c* 后， 权重和从 7.301 掉到 3.301。若不同步缩放，等于偷偷放松了「最小干预」的强度； 所以整体 ×2.212 拉回原量纲，ρ=15 继续锚定（口径 A）。33 题作答、空题 4/4 通过。

内容保留是强偏好而不是硬约束：语义抛光阶段要允许合法改字， 所以改正文按幅度扣分、不判死。要恢复「零改动」硬约束，把 content_hard=True 即可。

4. model2：审美量化

4.1 A_soft：平滑目标形式（现口径）

目标 t 取已录用语料中位数，尺度 s 取到 p5 / p95 的距离； 损失在目标处为 0、两侧严格单调、有界（封顶 3.0）。页 → 文档用「最差 5% 均值 + 全体均值」 各半：既对局部异常页敏感，又不被单页主导。

这一形式是阶段 10 换掉的旧「带内恒 0」写法：旧写法会让 20 页里有 8 页总分为 0、 排序信号被抹平，且把「过满」当缺陷（与人的偏好相反）。换形式后人工排序 Spearman 0.3146 → 0.4586，并列 8/20 → 0/20。

4.2 体检结论：8 个指标里只有 3 个在干活

90 篇 / 1502 页语料 + 8 个受控坏版面变体，两套体检交叉判定：

指标篇内损失极差只看正文页坏版面敏感性处置

top_bottom_ratio（上下失衡）0.4680.2970.526 保留

读法要小心：max_gap 在正文页上完全不动（0.000），因为正常正文页没有大空洞—— 这恰恰是它的职责。只看语料会把它误判成死数；必须配「坏版面敏感性」这套体检， 它在那里是最强的（1.384）。反过来，bottom_blank 两项指标都接近 0，删掉没有风险。

另外查出两个口径漏洞，列入 v2：① max_gap 会把末页自然留白当成页中大洞 （干净的合成稿就吃了 0.379 的罚分）；② ink_ratio 的变异 97% 来自页类型 （整页图页密度天然低），不按角色分层就是在量「这页是不是图页」。

4.3 A_profile：为什么 λ 仍然是 0

A_profile 量的是「与同会议·同角色语料的偏离」，不是「缺陷」。阶段性外部验证里， 源码级退化造成的 4 篇坏稿，它 0/4 与缺陷指标同向——因为 TeX 在断页处把问题吞掉了， 渲染结果逐位不变。所以在「把缺陷敏感与常态偏离拆开」之前，λ 必须保持 0； 代码里有 assert_lambda_allowed 硬拦截，防止悄悄开。

6. 局部 vs 整体

M₁ 的 P 是全文按次数求和，一个烂页会被别页的好摊平；M₂ 本来就有局部/整体聚合—— 两条线口径不一致，报告里也看不出「哪一页最差」。阶段 15 补了一层只做归因、不改判定的诊断：

归因对象怎么落到页
日志类缺陷（行溢出 / 欠满 / 表格超宽）源码行号 → SyncTeX → PDF 页号
源码卫生项、[H] 强排、参数不稳定同上（扫描自带行号）
渲染层视觉缺陷（内容孤立、近空白页）本来就有页号
vbox、浮动体警告、其余警告、质量宏缺失归不到页，单列「未归属」

实测 examples/issues.tex（3 页）：P 页均 1.311、最差页 1.900、全篇 5.933 （其中 2.0 归不到页）。第 3 页是「近空白页」，是全篇最差的一页， 但在全篇 P 里只占 10%——这就是「整体分摊平局部病灶」的具体例子。

边界（用户 11-02 拍定）：不加最差页项（ρ_peak·P_peak）、不做同类缺陷饱和、 不改 M₁ 公式。局部层只用于诊断与报告，不作为优化目标——因为动作面大多是全局的 （边距、字号、浮动体参数），以单页分为目标会诱导「修好这页、害了别页」。

8. 可信度与局限（必须写进论文）

  1. ρ 是单评分人、5 类缺陷标出来的，区间约 [5, 32]；两轮中位 16.7 / 13.3。 小数点后的精度没有意义。
  2. P 有 4 项仍是先验（fig_overwide / warn / macros_missing / unstable_spec）， 代码里逐项标注，不冒充标定结果。
  3. 指标判定对样本量敏感：27 篇样本时 `top_blank` 被判保留、`max_gap` 被判分层； 扩到 90 篇结论才稳定。这条本身就是方法学局限。
  4. 角色是像素代理，不是语义角色（不知道那页是不是 references / appendix）； 真正的 roles.py 走矢量层、成本高，闭环里跑不动。
  5. A_soft 不是人类审美评分：与人的一致性只有 20 页排序 Spearman 0.46 （n=20 时标准误约 ±0.2）与 12 对成对比较。
  6. 两套口径不可混比：在线是像素层、离线是矢量层，只能比方向，不能比绝对值。
  7. 「全局最优」不声称：只保证「评分可复现、方向可验证、退化会变差」。
