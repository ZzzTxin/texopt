# 阶段 5 交付：评测与验收协议（方案 12.1-12.6）

> 对应设计方案第十二章（评测与验收协议）与 12.6（验收门槛）
> 代码：`texopt/evalproto.py`（协议实现，纯标准库）、`texopt/aesthetic.py`（12.6 的 `drop_dims` 剔除）、`texopt/shadow.py`（门槛自动加载）
> 工具：`datasets/conf-specs/tools/eval_protocol.py`（全流程 CLI，离线跑缓存指标）
> 产出：`metrics/profiles/eval_protocol.json`、`eval_report.md`、`eval_gate.json`
> 测试：`tests/run_tests.py::stage5_tests()`（22 项，纯逻辑）

## 1. 一句话

审美没有客观 ground truth，所以模型必须**可证伪**：阶段 5 把方案 12 章的五项强制检验
落成可复算的协议 —— 负样本注入（12.1）、假阳率（12.2）、会议可分性（12.3）、
稳定性与可复现性（12.4）、与人类判断的相关性（12.5，本阶段未采集，如实记 null），
并按 12.6 给出**逐指标验收门槛**：未通过三项检验的指标只能作报告项，不得参与 A。

诚实边界（写进报告，不许包装）：

* 本协议检验的是**实现与口径的自洽性**，不是「模型与人类审美一致」；
* 12.2 的「误报」定义是**页级 D² 超过阈值**，它衡量「合法但特殊的版面被报异常」的比例，
  不涉及「人眼是否觉得这片空白难看」；
* 12.5 需要人类成对比较数据，**本阶段未采集**（阶段 7 做 Bradley-Terry 标定），如实输出 null。

## 2. 协议实现（`texopt/evalproto.py`）

| 编号 | 检验 | 实现要点 |
|---|---|---|
| 12.1 | 负样本注入 | **两级**：①指标层（在缓存指标上对单页做阶梯外推，快、全库可跑）②渲染层（真实编译退化版 .tex，验证「感知层→评分」整条链路）。退化方向**不写死**，按「推离本档常态区间」逐页选取；判据 = A_profile 单调上升（容忍 0.1% 回落，见 F3）+ 退化页定位命中 |
| 12.2 | 假阳率 | k 折（**按论文**分层留出）交叉：训练集重建档案、训练页定阈值、留出页测误报。同时报三种阈值口径：参数化（χ², p<0.05）、经验校准（训练集 D² 分位）、归档阈值；并给 P95/P96/P97 的**假阳率—敏感度权衡表** |
| 12.3 | 会议可分性 | 论文级画像特征（各维页级中位数，稳健标准化）做 1-NN 留一分类，与均匀随机/多数类基线比较，**置换检验**（100 次）给 p 值 |
| 12.4 | 稳定性 | (a) 同文档重复测量逐字段 diff；(b) 同一 PDF 在两个 DPI 下提取，比较判定维漂移；(c) 同一 `.tex` 重复编译，比较页级指标漂移。目标 < 5% |
| 12.5 | 人类相关性 | 接口就位（`spearman_rank`，样本 <8 对不给结论）；数据未采集 → null |
| 12.6 | 验收门槛 | 逐维「12.1 单调 ∧ 12.2 假阳 ∧ 12.4 稳定」→ `pass` / `report-only`；`eval_gate.json` 被 `shadow.evaluate_pdf()` 自动加载，未通过的维**不参与判定**（只报告） |

## 3. 结果

### 12.1 负样本注入

指标层：**81 组**「真实页 × 阶梯退化」试验（覆盖 body / title / section-head / references /
appendix / figure-page 等角色）：

* A_profile 单调上升 **100%**（容忍 0.1% 回落口径；零回落严格口径 94.6%）
* 逐维带外损失单调 **100%**
* 退化页定位（全页 D² 排序 top-3）**96.3%**，top-1 命中 63%，中位名次 1
* 定位按角色拆分：正文类角色几乎必中；`appendix` / `references` / `figure-page`
  这类页本身 D² 就高，注入后未必上升到第一，属**预期**而非缺陷（报告里单列）

退化方向按「推离本档常态」逐页选取，这是必须的：带外损失是**双向非单调**的，
同一维「变小」在某些页上是退化、在另一些页上反而是「回到常态」，
写死方向会把正确的非单调行为误判成失败（实测踩到 6/81 例）。

### 12.2 假阳率（目标 ≤ 5%）

| 口径 | 页数 | 误报 | 假阳率 | 结论 |
|---|---|---|---|---|
| 参数化阈值（χ², p<0.05） | 见 `eval_protocol.json` | — | **0.1592** | **不通过** |
| 经验校准阈值（训练集 D² P95） | — | — | **0.0571** | 接近目标 |
| P96 | — | — | 见报告 | — |
| P97 | — | — | 见报告 | — |

**结论（重要）**：卡方假设**不成立** —— 真实页级 D² 分布比 χ² 重尾（指标是重尾/混合分布，
且每页可用维数 k 不同），参数化阈值把假阳率抬到 15.9%，是目标的 3 倍。
→ 发布口径必须用**经验校准阈值**（按 role 取训练集 D² 分位），并在报告里同时给出
P95/P96/P97 的权衡表供阶段 6-7 选择（目标 5% 时应取比 P95 略保守的档）。
按 role 的细分表见 `eval_report.md`。

### 12.3 会议可分性

* 参与：11 个会议 / 每会 ≥20 篇
* 论文级画像特征 1-NN 留一准确率 **0.5288**（均匀随机 0.0909，多数类 0.1187）
* 置换检验 **p = 0.0099**（100 次置换）→ **显著高于随机**

结论：指标确实抓到了会议风格差异（11 类任务上 0.53 的准确率远高于随机的 0.09），
说明 profile 不是「无信息的噪声档案」。

### 12.4 稳定性与可复现性

| 检验 | 结果 |
|---|---|
| 同文档重复测量（逐字段 diff） | 完全一致 |
| DPI 变更（50 → 200 dpi） | 判定维最大相对漂移 **0.0**（8 维全部取自矢量/文本层，与 DPI 无关；像素代理量只作报告） |
| 同一 `.tex` 重复编译 | 见报告（目标 < 5%） |
| 可重跑/可追溯 | 全流程确定性（固定 seed）、报告带 `profile_version` / 工具版本，`eval_protocol.json` 完整留档 |

### 12.5 与人类判断的相关性

**未做**：需要人类成对比较数据，本阶段未采集；如实输出 `null`，不包装成「与人类审美一致」。
接口与统计口径（Spearman，<8 对不给结论）已就位，留待阶段 7。

### 12.6 验收门槛结论

逐维结论表见 `eval_report.md` 与 `eval_gate.json`（`dims` / `verdicts` / `dropped`）。
**未通过的维度会被在线影子评估自动剔除**（`shadow.evaluate_pdf` 默认加载
`eval_gate.json`，`A_profile` 只由通过门槛的维计算；被剔除的维仍在报告里保留）。

## 4. 阶段 5 修掉的真问题（都是协议跑出来的，不是设想）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| **F1** | 12.1 单调性一开始只有 **57%**：注入后 A_profile 纹丝不动 | 论文级聚合原是「按 role 取 P90，再跨 role 取 max」：①某 role 的既有大损失会**遮住**其它页的变化；②长文里单页退化在分位上几乎不可见 | 改为**逐页按本页所属档归一化**，再做 `0.5·前 k 大均值 + 0.5·均值`（k = max(1, 5% 页数)）。均值项保证「任何一页变差都抬高文档级值」，前-k 项保留严重性 —— 改后单调率 100%。**注意：A_profile 数值随之变化，全库影子报告已重跑** |
| **F2** | 注入「缩小图片」在某些页上 A 反而下降 | 该页的图/文比本来就**低于**常态区间，继续变小是「回到常态」 | 退化方向改为逐页按「推离本档常态」选取（两侧都试，取损失单调且增幅最大的一侧） |
| **F3** | 少数试验出现 3e-5 级别的 A 回落 | D² 是二次型，Σ⁻¹ 有非对角项（维相关）时，**单维外推可能让 D² 略降** —— 马氏几何的合法行为 | 单调判据加 0.1% 相对容差，并同时输出「零回落」严格口径（94.6%），两个数都如实报 |
| **F4** | 卡方阈值假阳率 15.9%（目标 5%） | 指标重尾 + 每页可用维数不同，χ² 假设不成立 | 12.2 增加**经验校准口径**（训练集 D² 分位）+ P95/96/97 权衡表；12.6 门槛按经验校准口径计 |
| **F5** | `spearman_rank` 与 `profile.spearman` 的最小样本口径不一致（3 vs 8） | 两处各写各的 | 统一为 <8 对返回 None，避免小样本假相关 |

## 5. 测试（22 项，纯逻辑）

`tests/run_tests.py::stage5_tests()`：折切分（确定性 + 分层 + 每篇只作一次测试）、
阶梯（域内/无界/无空间三种情形）、域裁剪、单调判据（容差内通过 / 大回落失败 / 平坦失败）、
方向选择（选「损失单调且增幅最大」的一侧、远低于下界时只能向下）、
文档级注入（单调 + 定位）、F1 聚合（单页变差必须抬高文档级值、前-k 均值语义）、
阈值校准（大样本下 P95 阈值 → 5% 附近）、多分位标定表（仓位数越高假阳率越低）、
可分性（可分数据高准确率 + 置换 p 值边界）、稳定性（0 漂移 / 10% 漂移超阈 / 重复测量一致）、
人类相关性接口（<8 对返回 None）、门槛规则（全过 pass / 假阳超阈 report-only / 缺项三条原因 /
多维多剔除）、**12.6 集成**（`drop_dims` 真的把该维从判定里剔除且不影响其它维）。
