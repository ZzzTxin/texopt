# 阶段 3 交付：留白结构化识别（五类 + region 列表）

> 对应设计方案第七章（7.1 五类定义 / 7.2 识别算法 / 7.3 空白质量式 / 7.4 门控原则）
> 代码：`texopt/whitespace.py`（识别器）、`texopt/extract.py`（元素与几何递入、页眉页脚识别、未锚图形计入）
> 产出：`page_metrics.v1` 的 `pages[].whitespace`（五类比率 + `regions[]`）
> 测试：`tests/run_tests.py::stage3_tests()`（12 项）

## 1. 一句话

阶段 1 只知道「这页有多少空白」；阶段 3 回答**「这些空白是什么性质」**——
是标题/段落/图表带来的正常间距、页边与栏边的自然余量、浮动体顶出来的空间，
还是**没有任何结构解释、被上下内容夹住的大片空洞**。

铁律：**White Space ≠ Bad Space**。五类里只有 `anomalous` 进惩罚项，其余四类只作画像特征。

## 2. 五类留白（口径）

| 类别 | 判定（本实现的证据） | 是否惩罚 |
|---|---|---|
| `structural` 结构性 | ① 邻接章节/小节标题（且高度 ≤ 0.25 版心高）② 高度 ≤ 2.4×行距（正常行距）③ 上下都有正文且高度 ≤ 3.2×行距（正常段距）④ 首页顶部的大标题区 | 否 |
| `boundary` 边界 | 贴合版心左/右/上边界或栏缝的窄条（行末参差余量、页面余量） | 否 |
| `float` 浮动体 | 纵向/横向邻接，或**把图/表框住**（L 形空白）；巨大者置信度下调，留待阶段 4 结合「浮动体—首次引用距离」判 | 视引用距离（阶段 4） |
| `trailing` 页末 | 落在一栏底部：栏末余量；标签区分 `doc-end`（文末）/`section-end`（段末短行）/`page-continue`（页中截断） | 否 |
| `anomalous` 异常连续 | **全宽连续空白带 ≥ 0.22 版心高**（或 ≥ 0.10 版心面积且带 ≥ 0.12）**且**无任何结构解释**且**上方有内容夹住 | **是**（唯一） |

`total_ratio` = 版心内空白格的完整量；**恒有 Σ 五类 == `total_ratio`**（<0.4% 的碎片不单列，面积计入 `structural`）。

## 3. 算法（方案 7.2 的落地）

```
1) 元素图   文本行（head / caption / text）+ 图/表浮动体 + 未被题注锚到的图形（loose graphics）
2) 空白掩码  A_usable（4pt 网格，已挖掉栏间距）− 元素并集 → 空白格集合
3) 连通域   4-邻接分解 → 候选区域 W_i（L 形/环形保持成一个区域）
4) 尺度     对每个区域算「整行全空的连续带」长度（band_run）与其中触底的那条（bottom_run）
5) 分类     按第 2 节的优先级规则打分，附邻接证据与置信度
6) 输出     region 列表（bbox / area_ratio / height_ratio / class / adjacent / confidence）
            + 五类比率 + n_regions / n_fragments / n_anomalous / max_anomalous_height_ratio
```

两个关键设计（都是被实测逼出来的）：

* **尺度用「整行全空带」而不是 bbox 高**。连通域可能是 L 形（居中的首页大标题周围）
  或环形（把浮动体包住），bbox 高会算出 `1.0`，据此判定必然误报。改为统计
  「该行在本栏范围内一个内容格都没有」的那些行，取最长连续段 —— 它才对应
  「视觉上一条连通的空白带」，也才和像素层的 `max_gap` 同义。
* **异常必须被上方内容夹住**。整列/半页本来就没有内容（末页只剩一栏、附录整页图旁）
  不是「空洞」而是「边界/页末」，因此 `anomalous` 额外要求 `上方存在内容元素`。

## 4. 阈值（都可复算，全部是几何量）

| 常量 | 值 | 含义 | 依据 |
|---|---|---|---|
| `CELL` | 4pt | 网格边长 | 与 `extract.GridMask` 一致，覆盖率/留白率共用一套量化 |
| `TOL` | 5pt | 邻接/贴边容差 | ≥1 个网格 + 余量 |
| `SPACING_MAX` | 2.4×行距 | 正常行距上限 | 语料实测行距比 ≈1.1–1.2（正文 10-11pt），2.4× 覆盖单双倍行距 |
| `PARAGRAPH_MAX` | 3.2×行距 | 正常段距上限 | 段间空白 ≤ 2–3 行 |
| `HEAD_MAX_H` | 0.25 版心高 | 「标题间距」上限 | 超过就不是标题间距，而是空洞 |
| `FLOAT_MAX_H` | 0.35 版心高 | 浮动体留白置信度分界 | 大空白仍记 `float`，但降置信度交阶段 4 |
| `MIN_AREA_RATIO` | 0.004 | 单列区域的最小面积 | 小于 0.4% 版心的碎片是网格/行距噪声 |
| `ANOM_HEIGHT` | 0.22 | 异常带的「高」阈值 | 约 3 行正文高度以上且无解释 |
| `ANOM_AREA` | 0.10 | 异常带的「面积」阈值 | 与高阈值并联，捕捉「宽而不太高」的空洞 |
| `BOTTOM_ANOM` | 0.35 | 栏底空白升级为异常的阈值 | 仅在「正文行未结束（满行）且非文末」时升级 → 坏分页 |
| `SHORT_LINE` | 0.75 栏宽 | 短行判定 | 区分「段末/章节末」与「正文被截断」 |

## 6. 页眉/页脚识别（阶段 1 遗留 L5，本次一并做掉）

* 判据：完全落在**版心上下沿之外**的行（版心上下沿由正文尺寸行分位得到）。
* 用途：① 不算正文覆盖（`coverage_text`）、不参与密度/平衡统计；
  ② 不作为留白的「结构解释」（否则页脚会把页末空白"解释"成结构性）；
  ③ 落盘到 `_signals.header_lines/footer_lines/header_text/footer_text` 便于审计。
* 语料实测：合订本会议集（如 ECCV/NSDI 的 proceedings 单篇）页眉命中 20–60 行/篇，
  普通单篇论文 0–10 行/篇。

## 7. 阶段 3 修掉的真 bug（都由实测暴露，非猜测）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| B1 | 整幅图被当成空白 → 炸出「异常空洞」（`original.pdf` 第 2 页，图占页面 40%） | 题注正则漏掉 `FIG. 1.`（大写缩写+句点）、`TABLE I.`（罗马数字）、`图 1 系统架构`（中文无分隔符）→ `anchor_floats` 锚不到浮动区，图形元素完全没进掩码 | 重写 `CAP_RE` + `caption_kind`；**并把未被题注锚到的图形（loose graphics）也计入覆盖与留白掩码** |
| B2 | 末页留白被误报为异常空洞 | `_last_above()` 用区域**下沿**比较，而栏底空白带的下沿就是栏底 → 永远找不到上方内容 → 走进「正文未结束」分支 | 改用元素**下沿**与区域**上沿**比较（`e["y0"] ≥ reg["y1"] − TOL`） |
| B3 | 居中标题（首页）与浮动体旁被误报 | 用 bbox 高做尺度，L 形/环形区域算出 1.0 | 改「整行全空连续带」尺度；`anomalous` 额外要求上方有内容；首页顶部空白单列 `title-page` |
| B4 | 「留白率」与「覆盖率互补量」对不上（差 2–5%） | ① 三个覆盖掩码各自去重，直接相加会重复计重叠区；② 更根本的是 **whitespace 丢掉了 <0.4% 的碎片** | 提取层改用**内容并集**的补集（新增 `_signals.ws_blank_complement` 供逐页互校）；碎片面积计入 `structural_ratio`，使 Σ 五类 == `total_ratio` |
| B5 | 页眉/页脚被算进正文覆盖与密度 | 从未单独识别（只按字号过滤 `main`） | 按版心上下沿识别并全文排除（见第 6 节） |

## 8. 实测

* 抽检 6 篇（ECCV/NSDI/IJCAI/OSDI/arXiv，97 页）：`|whitespace.total_ratio − 内容并集补集| ≤ 0.005`
  （差异仅来自 4pt 网格量化与 4 位小数取整），**恒等式成立**。
* 抽检 10 篇（143 页）：异常页 2 页（≈1.4% 页级），远低于方案 12.2 的 ≤5% 假阳率目标；
  异常都落在「正文被顶到页中、下方大片空白」的坏分页页上。
* 性能：约 **0.23–0.31 s/页**（含 4pt 网格 + 连通域 + 分类），全库 10538 页量级可接受。
* 全库重跑（`extractor 0.2.0`）与档案重建结果见 `docs/stage2_profile.md` 第 6 节与 `datasets/conf-specs/metrics/profiles/`。

## 9. 已知局限与后续

| # | 局限 | 影响 | 计划 |
|---|---|---|---|
| S1 | 分类是**邻接证据**规则，不是语义理解 | 「标题下方的空白」与「恰好挨着标题的空白」区分不了 | 阶段 4 用负样本注入 + 轻量分类器（方案 11 章可选增强） |
| S2 | 浮动体留白不判「距离首次引用多远」 | 图被顶走造成的空白目前只记 `float`（不惩罚） | 阶段 4：cross-ref 解析 + 引用距离指标 `float_ref_distance` |
| S3 | 「章节末/文末」只用「最后一行是否短行 + 是否文档末页」判定 | 少数页会把页中截断误判为段末 | 阶段 4 用 role + 跨页段落连续性判定 |
| S4 | 数字/表格占位（`TABLE I.` 之类）识别后仍不解析表格结构 | 覆盖仍是「题注锚定区」的近似 | 需表格结构识别（阶段 4+，方案外延） |
| S5 | 图形元素被计入覆盖后，覆盖率的绝对水平比 0.1.0 版本略高 | 与旧语料数字不可直接比 | 全库已按 0.2.0 重跑，`docs/stage2_profile.md` §6 已同步 |
