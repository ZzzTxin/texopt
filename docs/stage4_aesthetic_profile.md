# 阶段 4 交付：多维异常检测（马氏距离）+ 非单调带外损失 A_profile（影子模式）

> 对应设计方案第九章（9.3 马氏距离）、第十章（10.1-10.3 带外损失与权重路径）、第十三章（13.1-13.5 集成与成本）
> 代码：`texopt/aesthetic.py`（判定模型 + 构建期档案扩展 + 在线评估）、`texopt/shadow.py`（λ=0 影子接入）
> 构建：`datasets/conf-specs/tools/build_profile.py`（新增 `mahalanobis` 块，档案升到 `profile_version = v2`）
> 离线评估：`datasets/conf-specs/tools/shadow_report.py`
> 产出：`aesthetic_profile.json` 的 `mahalanobis` 块、`aesthetic_shadow.json`（在线）、`shadow_report.json` / `shadow_summary.md`（全库）
> 测试：`tests/run_tests.py::stage4_tests()`（22 项，纯逻辑、不依赖 PDF）

## 1. 一句话

阶段 2 给出「正常范围」（分位区间），阶段 3 给出「空白是什么性质」，阶段 4 把两者合成一个**可计算的偏离度**：
用**马氏距离**回答「这页算不算异常」，用**非单调带外损失**回答「异常在哪个指标上」，
合成 `A_profile`——但**以 λ=0 影子模式接入**：只报告、不参与任何接受/回滚判定。

诚实标注（必须写进论文与汇报）：本模块量化的是**页面级「常态偏离」（typicality）**，
不是人类审美评分；权重为方案 10.3「步骤一：等权」，只保证**排序可复现**，
不主张绝对分数跨会议/跨档可比。

## 2. 三个量

| 量 | 回答的问题 | 口径 |
|---|---|---|
| `D²`（马氏距离） | 是否异常 | 在**同一档**（venue\|role 等）内，把该页 8 维指标标准化后，用**稳健中心 + 收缩协方差**求马氏距离；卡方上尾概率 `p` 作为页级异常判据（`p < 0.05` 记异常页） |
| `band loss`（带外损失） | 哪里异常 | 每维的目标区间是档案的 `[P25, P75]`（区间过窄回退 `[P10, P90]`）；**区间内损失恒为 0**（非单调）——只有落到区间外才按 `|超出量| / IQR` 计罚；低于下界权重 `W_LOW = 1.2`、高于上界 `W_HIGH = 1.0`（版面偏空通常比偏满更刺眼） |
| `A_profile` | 总体偏离多少 | `A_profile = mean_i norm_loss_i ⊕ norm_D²`（阶段一等权，各维损失与 D² 项都除以其「同档 P90 参照值」归一化） |

**非单调是核心**：旧口径是「单调惩罚」（越满/越空越罚），会把正常双栏文章的满版正文也罚掉；
现在只有**偏离常态区间**才产生损失，区间内一律 0。

方向特例：`direction = "low"` 的指标（越低越好）只罚「过大」，以本档 `P75` 为唯一上界。
图/图表文本比这类**正比率重尾**维度在 `log1p` 域做区间/尺度/标准化（`LOG1P_DIMS`），
单维归一化损失再截断到 `LOSS_CAP = 20`，防残余重尾维度主导总分。

## 3. 分层与回退链（方案 5.2 / 5.3）

在线按顺序挑档，**低可信度档直接跳过**（`min_conf = medium`）：

```
venue|role  →  role|layout  →  role
```

* `venue|role`：主档（67 档），判定最贴合该会议该类型页；
* `role|layout`：**栏数条件化**（14 档），为小样本会议兜底；
* `role`：跨会议通用档（7 档），最后回退。

**为什么必须加 `role|layout`（实测逼出来的）**：小样本会议（n<16）的 venue 档可信度不足，
只能回退到 role 层，而 role 层是**跨栏数混合**的——单栏论文在混合档里必然离群，
假阳率一度冲到 40%+。按栏数条件化后回到可用水平（见第 7 节）。

## 4. 稳健化（本机无 numpy/scipy，全部手写）

| 环节 | 做法 | 理由 |
|---|---|---|
| 中心 / 尺度 | 中位数 / IQR（分位直接取自档案） | 抗离群，不引入均值方差假设 |
| 截断 | 标准化后 `\|z\| > 4` 截断 | 限制单页对协方差的影响 |
| 收缩 | `Σ = (1-δ)·R + δ·I`，δ 由 **Ledoit-Wolf 解析式**估计 | n 小 / 维高时自动加大收缩，避免 `Σ⁻¹` 不稳（9.3 明确要求） |
| 求逆 | Cholesky → 失败逐级加 jitter → 再失败退 Gauss-Jordan | 对称正定优先用 Cholesky，退化时仍有确定输出（`solver` 字段落盘可审计） |
| 卡方 | 手写 `chi2_sf`（含 Wilson-Hilferty / 级数回退）与 `chi2_isf` | 无 scipy；`chi2_sf(3.841,1)=0.05`、`chi2_isf(0.10,8)=13.362` 已单测校准 |
| 缺维 | 该页缺失的维**从本次判定中剔除**（子矩阵求逆，`k_used` 落盘） | 不是补零——补零会制造假异常 |

## 5. 构建期 vs 在线

**构建期**（`build_profile.py` → `AE.build_block()`，每档一次）：

1. `select_dims()` 选判定维度：优先 `DEFAULT_DIMS`（密度/留白/图文比/平衡/行距/对齐/一致性/图件各一），
   同一高相关族只留一个代表，按覆盖率降序补足，上限 8 维 → 全库同定 8 维；
2. 缺值过多的维度逐个剔除，保证完整样本 ≥ `min_pages = 30`；
3. **零膨胀 / 常数维不参与判定**：众数占比 ≥ `MODE_FRAC_MAX = 0.5`（如正文页的 `coverage_table` 恒为 0）→
   IQR = 0，任何非零都会被算成「巨大超界」，会把分布带偏；
4. 每维落盘 `center / scale / bands / direction`，并估计 `corr / delta`；
5. 用**本档语料自身**的回代结果定参照值：`d2_ref = P90(D²)`、`loss_ref[dim] = P90(loss)`（归一化基准）。

**在线**（`shadow.evaluate_pdf()` → `AE.evaluate_doc()`，只查表，不重新统计）：逐页算 D² / p / 带外损失，
论文级聚合取 `median`（画像）与 `P90` / `max`（异常判定），输出逐页明细 + 最偏离维度。

## 6. 影子模式接入（13.1 / 13.2 / 13.4 / 13.5）

* **λ = 0**：`A = A_defect + λ·A_profile`，`SH.LAMBDA = 0.0`。`A_defect`（`score.py` 的确定性缺陷加权计数）
  口径**完全不变**，回归照旧；
* 接入点 `core.Optimizer._shadow_eval()`：基线快照与 `finalize()` 各跑一次，结果写入
  `state.json.aesthetic_profile`、工作目录 `aesthetic_shadow.json`，并在 `report.md` 增加
  「审美档案影子评估（λ=0）」章节（含最偏离维度与门控结论）；
* **异常隔离**：影子失败绝不影响主流程，一律降级成 `{"status": "error"}` 报告项；
* **门控** `shadow.gate()`（13.2）：只有当「缺陷类指标不变差（hard 不增、`A_defect` 不增）」且
  `A_profile` 确有改善时才允许以审美为由接受改动。影子模式下该门控**不参与**主循环，只用于报告；
* **成本**（13.5）：底层页级指标阶段 1-3 已缓存，在线只算待优化那一篇；
* 环境变量 `TEXOPT_NO_SHADOW=1` 可整体关闭（受限环境跑回归用）。

## 7. 被实测纠正的口径（都是真问题，不是设想）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| A1 | 小样本会议的判定假阳率异常高（一度 40%+） | 小会议 venue 档可信度不够 → 回退到**跨栏数混合**的 role 档 → 单栏论文在混合档里必然离群 | 新增 `role|layout` 层（方案 5.2 栏数条件化），回退链变成 `venue\|role → role\|layout → role` |
| A2 | 某些维度把整档判定带偏 | 零膨胀 / 常数维（如 `coverage_table` 在正文页恒 0）：IQR=0 → 任何非零都是「巨大超界」 | `build_block` 剔除众数占比 ≥0.5 的维度并在 `notes` 里如实记录 |
| A3 | 重尾维度（图/图表文本比）单维主导总分 | 分母趋零时比值爆掉，归一化损失无上界 | `ratio.*` 在 `log1p` 域处理 + 单维损失截断 `LOSS_CAP` |
| A4 | 个别篇 A_profile 高得离谱（如 `s-acl-2025-012` = 12.3） | 不是版面问题，是**数据问题**：46 页里 38 页是 references（proceedings 合订本） | 影子报告加「疑似合订本」判据（≥25 页且 references 占比 >0.6），**排除出统计**并单列审计表 |
| A5 | `shadow_summary.md` 的「疑似合订本」列全是 0，而正文又说有 26 篇 | 该列读 `v.get("n_suspect", 0)`，但 `report["venue"]` 的字典推导压根没写这个键 → 永远取默认值 | 补上 `"n_suspect": v["n_suspect"]` 并重跑报告（现为 acl 3 / emnlp 7 / icml 7 / neurips 9 = 26） |

## 11. 已知局限与后续（对应方案第十二、十四章）

| # | 局限 | 影响 | 计划 |
|---|---|---|---|
| L1 | 全库评估是 **in-sample** | 异常率偏低，不能当假阳率 | 阶段 5：负样本注入单调性 + 留出集假阳率 ≤5% + 会议可分性 + 渲染/时间稳定性 |
| L2 | 权重仍是等权（方案 10.3 步骤一） | 分数只有排序意义，绝对值不可跨档比 | 阶段 6：负样本消融校准 → Bradley-Terry 人类成对比较（步骤二、三） |
| L3 | λ 仍为 0，未接入主循环判定 | 审美分不影响接受/回滚 | 阶段 6：λ 校准后打开，门控（13.2）转入硬约束 |
| L4 | 合订本/结构异常篇靠启发式排除 | 少数篇可能误排或漏排 | 阶段 5 用结构信号（页数 + references 占比 + 页眉模式）正式判定 |
| L5 | 马氏距离对「非凸常态」不敏感 | 双峰分布（如单双栏混排并存）可能被当成两个离群 | 分层已缓解（role×栏数）；后续可上混合模型，需先评估收益 |
